<objective>
Add a full-US-market equity roster (NYSE + NASDAQ + AMEX common stock, delisted
included) as a NEW sibling of the existing NASDAQ-only roster, plus a resumable,
concurrent Tiingo bulk daily-bar ingest entry point that persists under
`QUANTLAB_DATA_DIR` (= /Volumes/SSD/data) over 2006-01-01..today.

Purpose: the existing `nasdaq_all` roster covers one exchange. Cross-sectional
US-equity research needs the whole listed market, and needs it survivorship-bias
free — every ticker that traded during the window, including the ~6.9k that
delisted after 2006-01-01.

Output: a `us_all` universe category, an interval-overlap roster query, a
concurrent/resumable acquisition class, a storage-sizing guard, and a glue-only
`ingest_us_equity.py` with a dry-run mode.

<planning_observations>
Every number below was measured live at planning time (2026-09-06) by
downloading `supported_tickers.zip` and reading the machine's own disk/RAM.
Do not re-derive them by guessing; re-measure if a value looks wrong.

**1. Tiingo `exchange` token vocabulary (108,561 rows total).** Observed
distinct values with counts:

```
NMFQS 49827 | PINK 20695 | NASDAQ 10969 | NYSE 9296 | SHE 3808 | SHG 3429
BATS 2016 | OTCMKTS 1992 | NYSE ARCA 1532 | OTCGREY 1518 | EXPM 931
OTCBB 602 | OTCQB 447 | OTCCE 389 | AMEX 386 | NYSE MKT 224 | OTCQX 204
(empty) 135 | OTCD 61 | SHGB 44 | SHEB 42 | LSE 11 | NYSE NAT 3
```

The AMEX appears under TWO tokens, because Tiingo never re-labelled the
historical rows across the exchange's AMEX -> NYSE Amex -> NYSE MKT -> NYSE
American renames: `AMEX` (386) and `NYSE MKT` (224). There is no
`NYSE American` token. Both must be in the filter or ~224 tickers vanish.
`NYSE ARCA`, `NYSE NAT` and `BATS` are DIFFERENT exchanges (ARCA is
predominantly ETFs) and are deliberately excluded — D-01 says NYSE, NASDAQ,
AMEX. The empty-string exchange is excluded for free by exact-match `is_in`.

**2. Filter yield.** `exchange in (NASDAQ, NYSE, AMEX, NYSE MKT)` AND
`assetType == "Stock"` AND `priceCurrency == "USD"` -> **16,138 rows /
15,425 distinct tickers** (NASDAQ 9318, NYSE 6284, AMEX 336, NYSE MKT 200).
Rows exceed tickers because ~700 tickers carry more than one exchange row
(re-use / venue migration) — interval-overlap queries must therefore
`.unique()` on symbol, exactly as `get_symbols_as_of` already does.

**3. `endDate` is ALWAYS populated in this subset** — never empty, not even for
currently-listed names (those carry the last trading day, e.g. `2026-09-04`).
The synthetic fixture in `tests/conftest.py` uses empty `endDate` for live
tickers; that is fixture convention, not source reality. Keep the
`end_date.is_null() | end_date >= ...` null-tolerance in queries anyway, since
the S&P/NDX membership categories DO produce real nulls for open intervals.

**4. The 2006-01-01 cut removes exactly ONE row** (a 1997 delisting). It is
still correct to apply it per D-05, and it is the same interval-overlap
predicate that KEEPS the post-2006 delistings — `endDate` year histogram:
2009:41, 2013:142, 2016:425, 2019:547, 2022:994, 2023:1159, 2026:8561.
Roughly 6.9k of the 15.4k tickers ended before today. That gap between 8,561
currently-listed and 15,424 total IS the survivorship bias this exists to
avoid.

**5. Sizing (window 2006-01-01 .. 2026-09-06, ~5,215 trading days).**
15,424 symbols x 5,215 days = **80.4M dense grid cells**; ~29.6M are real
observations -> **density 0.368**. At 12 Tiingo EOD variables:

| Artifact | Estimate |
|---|---|
| dense `[timestamp, symbol]` float64 Zarr | **~7.2 GiB** |
| dense float32 | ~3.6 GiB |
| raw per-symbol parquet (~29.6M rows) | **~1.7-3 GiB** |
| `/Volumes/SSD` free | **120 GiB** |
| this machine's RAM | **16 GiB** |

**Disk is not the constraint — RAM is.** `StockDataset._raw_data_to_xr()` does
`pl.concat(...).collect().to_pandas().set_index([...]).to_xarray()`, which
materializes the FULL dense 7.2 GiB grid plus the 29.6M-row pandas frame plus
conversion scratch, on a 16 GiB box. It will OOM. This is why Task 3 ships an
`assert_dense_panel_fits()` guard that raises with the numbers BEFORE the
allocation, and why the Zarr conversion is opt-in (`--to-zarr`) rather than the
default tail of the ingest. The default run produces raw parquet only — which
is fine, because raw acquisition parquet is an acquisition-layer implementation
detail (CLAUDE.md), and narrowing `--symbols`/`--start-date` for the Zarr step
is a one-flag decision rather than a rewrite.

**6. No new dependencies.** `joblib`, `polars`, `requests`, `tiingo` are all
already in `pyproject.toml`. There is no package-manager install task in this
plan, so the Package Legitimacy Gate does not apply.

**7. Baseline verify command (grounded, re-run at planning time).**
`uv run pytest tests/ -q` -> `123 passed in 7.45s`. Do NOT use bare
`uv run pytest`: `backtest/test_strategy.py` has a PRE-EXISTING collection
error (`TypeError: Missing required arg`) unrelated to this work, which
aborts collection. Always scope to `tests/`.
