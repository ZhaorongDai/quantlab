package DATA: it lives inside the config package and travels with it. Two
callers locate it today and they disagree about how. The nautilus loader

package-derived, not repo-root-relative. This is the whole point of the task.

directory named after this package, below wherever you are" is a default that
resolves correctly exactly once and wrongly everywhere else. A package-derived
path also keeps doing the right thing for this repo's own editable install,
where it lands on the tracked file the CLI is supposed to rewrite.
