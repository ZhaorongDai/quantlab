## The design decision inside this gap, and its rationale

`03.1-VERIFICATION.md` offers two acceptable closures: raise, **or** a documented, tested narrowing
such as warn-and-clamp. **This plan chooses RAISE, with an INCLUSIVE boundary** (`start_date <
PIT_COVERAGE_START` raises; `start_date == PIT_COVERAGE_START` is accepted).

Four reasons, in order of weight:

1. **`.planning/REQUIREMENTS.md` DATA-05 says so literally**: "超出可回溯起点的查询必须**显式报错**而非
   静默返回不完整名单". `get_symbols_in_range()` is a 查询. 显式报错 is a raise, not a log line.
2. **Symmetry is the gap.** SC-3 says "a membership query"; the class exposes two; one raises. A
   different resolution on the sibling would leave two membership queries with two contracts, which
   is the condition that produced this gap in the first place.
3. **No caller in this repository needs an unbounded-left sweep on a membership category.** Full
   enumeration (`rg 'get_symbols_in_range'`, non-`.planning` hits): `utils/cli.py:315` (reached only
   from `ingest_us_equity.py:352`, whose `--start-date` defaults to `2016-01-01` and whose
   `--category` defaults to the boundary-free `us_all`); `tests/test_universe.py` (four tests, all
   `us_all` from `2006-01-01`); `tests/test_ingest_tiingo_universe_wiring.py:178` (a fake with no
   body); `example/constituent.md` (prose). The project's "from the beginning" sentinel
   `enums/constant.py:Date.START_DATE = "1900-01-01"` is a **dataset-config** default consumed by
   `BaseDatasetConfig` and `IndexConstituentDataset._clamp_coverage_start()`; it is never handed to
   a catalog query. The hypothetical historical-sweep idiom the raise would break does not exist here.
4. **Warn-and-clamp would buy almost nothing.** Every membership interval already starts at or after
   its category's coverage start, so raising `start_date` from `1900-01-01` to `1976-07-01` does not
   change the overlap predicate's result set at all. Clamping would return the identical censored
   roster plus a `logger.warning` — which is precisely the "the caller cannot tell" failure the gap
   names, only noisier.

**Why the panel side legitimately does the opposite, and must be left alone.**
`base/constituent.py:_clamp_coverage_start()` CLAMPS (and warns only when the caller asked for an
earlier date, staying silent for the inherited sentinel). That is correct there and wrong here, for
one reason: it processes a **config default** that the framework itself supplies, so raising would
make every default construction explode; the catalog query processes a **caller-supplied date**,
where a wrong value is a question the caller actually asked. Task 3 writes that distinction into
both docs so nobody later "aligns" them by deleting one.

**Reversibility: `reversible`.** Undo cost is one deleted call inside one method of one file. There
is no on-disk format, no wire format, and no contract published outside this repository; every
caller is enumerable with a single `rg` (four sites, listed above), and all of them pass in-coverage
or boundary-free arguments today. This is NOT a one-way door, so no `checkpoint:decision` is
inserted and the plan stays `autonomous: true`.
