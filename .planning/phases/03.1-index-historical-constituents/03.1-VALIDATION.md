## Sampling Rate

- **After every task commit:** Run the quick command for the file that task touched
- **After every plan wave:** Run `uv run pytest tests/ -q`
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** ~10 seconds

`tests/conftest.py` exists. Wave 0 for this phase is therefore about **fixtures,
not framework**, and each fixture is delivered inside the plan that first needs
it rather than by a separate Wave-0 plan:

- [ ] Offline fixtures for the two membership change tables — the S&P one already
      exists (`tests/conftest.py:sp500_changes_html_fixture`); the NDX one

      **03.1-02 Task 1**
- [ ] A small hand-built interval set with known removal dates, a still-open
      membership, and a delisted symbol, so the densification edge cases from
      Finding 6 are assertable against arithmetic anyone can check by hand:

      **03.1-03 Task 2** (module-local per 03.1-PATTERNS.md §6 — only one module
      consumes it, which also keeps 03.1-03's file set disjoint from 03.1-02's)
