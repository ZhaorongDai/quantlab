## Wave 0 Requirements

Existing infrastructure covers the framework need — pytest is installed and
`tests/conftest.py` exists. Wave 0 for this phase is therefore about **fixtures,
not framework**:

- [ ] Offline fixtures for the two membership change tables (S&P + NDX) — saved
      HTML or pre-parsed frames, so no test performs a live fetch
- [ ] Offline fixture for the NDX current-constituent anchor (102 rows, no
      `date_added` column — the shape Finding 5 observed)
- [ ] A small hand-built interval set with known removal dates, a still-open
      membership, and a delisted symbol, so the densification edge cases from
      Finding 6 are assertable against arithmetic anyone can check by hand

---

## Manual-Only Verifications

- **Live-source drift** — that the real Wikipedia/anchor pages still parse. This
  cannot be a suite test without making CI depend on third-party HTML. The
  cached-snapshot fallback plus the row-count monotonicity check (Finding 4) are
  the in-code defenses; a manual refresh run is the check.
