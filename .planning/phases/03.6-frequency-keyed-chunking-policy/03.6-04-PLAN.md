<objective>
Amend every locked text this phase falsifies, in place, preserving the original wording
beneath the amendment — and formally WITHDRAW requirement DATA-08, whose capability SC-3
deleted.

Purpose: SC-8 is not bookkeeping. Four separate documents currently assert that the
dense-panel guard is kept, that a refusal names a fitting remedy, and that a caller can
ask for a conversion's predicted peak memory before any memory is allocated. All three
claims are now false. A planning tree that asserts a control it no longer has is worse
than one that never claimed it, because the next reader — human or agent — plans on top of
it. This repository has already had that failure four times in phase 03.4 alone.

The discipline is 03.6 D-18, which SURVIVES the scope amendment UNCHANGED and governs
every edit here: annotate in place, beneath the original, preserving the original wording.
Wholesale rewriting is explicitly rejected — a reader of 03.5's CONTEXT must not lose the
fact that a different decision once stood there.

One of the falsified texts is this phase's OWN contract. ROADMAP 03.6 SC-5 says `--chunk`
"stays REQUIRED"; the live argument has never been required, and the developer's decision
was to leave the flag alone. That is a defect in the paraphrase, not in the flag, and it is
dangerous in a specific way: a downstream verifier reading SC-5 either marks it unmet or
"fixes" the code toward the wording — and the second outcome is a real regression caused by
a documentation slip. Task 1 part (e) corrects the CONTRACT, under the same D-18 discipline,
and leaves `quantlab/utils/cli.py` untouched.

Output: five annotated `.planning/` documents and two de-staled `example/` guides.
</objective>
