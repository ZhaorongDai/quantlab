# Phase 03.10 Plan 05: CRSP Symbology Completion Summary

**PERMNO -> period-correct ticker: an overlap-driven class-collision pass that separates BRK.A from BRK.B before either row carries a tradingsymbol, a delisting carry that keeps Lehman's -60% day in the panel, and a three-rule row-level resolver that refuses rather than merge two securities into one column.**

## Accomplishments

- **The collision pass (rule 6).** Two DIFFERENT PERMNOs whose symbols came out equal over overlapping intervals are respelled `base.cls` from their OWN share class. This is the only rule that can separate `BRK.A` from `BRK.B` over 1996-2002, when NEITHER Berkshire row carries a `tradingsymbol` (live `C5`), and it is what makes the three live `BF` lines read `BF.A` / `BF.B` / `BF` on both sides of the 2002-01-02 tradingsymbol era.
- **Three deliberate exemptions**, each one a security CRSP did not rename: an interval with no class keeps the bare ticker (`WIN` 24803, `BF` 88279, live `L5_1`/`L6_1`); an overridden PERMNO is untouched (D-15); and a symbol that already spells its class is not suffixed twice.
- **The delisting carry** (RESEARCH Pitfall 3). `DelDlyDt` is the trading day AFTER the delisting date while the last `secinfoenddt` can be the delisting date itself, so the one row carrying the delisting return falls outside every interval. It now takes the last interval's symbol when `dlydelflg='Y'`, and the carry is counted. Every other uncovered row is dropped into `report['unlabelled']` with one loguru warning carrying the totals.
- **`resolve_collisions(frame, member_intervals=None)`** — active-over-delisting, then universe-member, then a `ValueError` naming up to 20 `(date, symbol, [permnos])` cells, the total, and both remedies. There is no fourth rule on purpose.
- **The full audit trail** for the plan-08 sidecar: `class_suffixed`, `nonconforming_symbols`, `unlabelled`, `delisting_carried`, `collisions` — all JSON-serializable, dates as ISO text.

## Decisions Made

- **Single-pass, not iterated.** A second collision round could only rename an interval a first round already separated; "the symbol depends on how many times we looked" is not a property a panel axis may have.
- **Overrides are exempt from the pass.** `symbol_overrides` means one fixed symbol for one whole history (D-15). A class suffix on top would contradict the thing the override was set for.
- **No double suffix.** A pair that rules 1-4 already spelled `ABC.B` is left alone rather than becoming `ABC.B.B`. It is still a collision — `resolve_collisions` refuses it, because the spelling genuinely cannot separate them.
- **Unclassed lines keep the bare ticker.** `WIN` 24803 and `BF` 88279 have no share class; suffixing them would rename a security CRSP never renamed, and the `BF`/`WIN` columns would then silently not exist.
- **`resolve_collisions` returns the caller's frame object unchanged when there is nothing to do**, preserving row order exactly — the per-PERMNO adjustment anchor in `CrspStockDataset._derivation` depends on the caller's sort.
- **`label_rows` tolerates a frame with no `dlydelflg`.** Such a frame simply has no delisting rows to carry; raising would make the symbology unusable for the membership panels of plan 09, which carry no daily flags.
