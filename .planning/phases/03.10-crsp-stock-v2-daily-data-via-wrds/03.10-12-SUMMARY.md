## Decisions Made

- **The RED tests stay unmarked.** Marking any of the four `xfail` would make the file green and erase the evidence plan 13 is measured against. The plan's `<verification>` demands exactly 4 failed, and that is what the file reports.
- **`WESTROCK_2024_ROWS` is not in the fake session's default row set.** `FakeCrspSession.reset()` still serves AAPL + Lehman + AAPL-1980 + QQQ. Adding WestRock there would have changed the corpus every other CRSP test sees for no gain; tests that want it pass it explicitly, which is also how `LEHMAN_2008_ROWS` is used at the row level.
- **The delisting row's type columns are NULL, as the live row is.** Before asserting on it, the D-10 filter carry was read (`quantlab/dataset/crsp.py:_apply_security_filter`): a `dlydelflg='Y'` row inherits its PERMNO's previous verdict, so the NULL-typed row is kept. Had it been dropped, the `is_delisting` and symbol-carry assertions would have failed for an unrelated reason and muddied the evidence.
- **`REQUIREMENTS.md` untouched.** `requirements.ready-ids` reports `0/4 requirement(s) ready to mark complete` for D-08/D-09/D-10/D-19 — sibling plans in this phase declare the same IDs and have not finished. Independently, marking them complete here would be false: this plan's whole purpose is to demonstrate that D-08 and D-09 are currently UNMET.
