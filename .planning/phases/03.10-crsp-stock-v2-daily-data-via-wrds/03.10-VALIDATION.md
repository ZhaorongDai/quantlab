## Sampling Rate

- **After every task commit:** run the task's `<automated>` command (a CRSP test file or selector).
- **After every plan wave:** run the full suite command and the baseline comparison.
- **Before `/gsd-verify-work`:** plan 11 Task 2 records the main-tree gate; the full suite must show no failing id outside the baseline.
- **Max feedback latency:** 180 seconds per task command.
