<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WRDS server -> raw tier | COPY output becomes on-disk shards |
| CLI/config window -> SQL | dates and PERMNOs become SQL literals |
| two CRSP vintages -> one raw root | a later annual release could overwrite part of an older one |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.10-07 | Denial of Service (self) | unbounded daily pull | high | mitigate | CrspVolumeProbe counts per (year, batch) before the pull; SqlVolumeGuard refuses above 20 GiB / 700M rows unless forced |
| T-03.10-08 | Tampering | vintage mixing | high | mitigate | `_vintage/wrds.json` stamp compared on every run; mismatch raises CrspVintageError before any COPY |
| T-03.10-09 | Tampering | malformed server pages | medium | mitigate | pinned columns, count check, uniqueness and ownership checks fail the batch; nothing is silently repaired |
| T-03.10-10 | Information Disclosure | driver error text | high | mitigate | every CRSP call routes through `WrdsSession._query`, which replaces the username with `$WRDS_USERNAME`; tested through the real session with fake_connect |
| T-03.10-11 | Tampering | SQL literals | high | mitigate | digits-only PERMNOs, `sql.Literal` for values, `sql.Identifier` for names; empty batch refused |
</threat_model>
