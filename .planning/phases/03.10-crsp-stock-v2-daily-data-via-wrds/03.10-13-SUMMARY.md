- **GAP-A closed.** `_NO_PRICE_FLAGS = ("DA",)` and a two-arm sentinel test exclude the no-price row *before* `abs(dlyprc)`, so raw `close` is NaN there rather than a fabricated $0.00 trade that contradicts the `-0.56%` `ret` on the same row. - **The WR-03 test widens the roster instead of extending `end_date`.** See `key-decisions` — the plan's recipe would have produced a test that passes with or without the guard, because the anchor gate refuses inside the derivation, before any report write, in both the old and the new ordering.
