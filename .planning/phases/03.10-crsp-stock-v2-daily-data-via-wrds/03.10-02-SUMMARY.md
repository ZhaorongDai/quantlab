## Decisions Made

Recorded in the frontmatter `key-decisions`. The three worth restating here, because a later plan will meet them:

- **`close = abs(dlyprc)`, not `dlyclose`.** `dlyclose` is null on bid/ask days, through the whole pre-1992 Nasdaq era and on delisting rows, while `dlyret` is computed from `dlyprc`. Using `dlyclose` would put a return chain and a price series that disagree into one panel — and the disagreement would be silent, appearing only as a wrong `adjClose` level.
- **A null `dlyret` contributes 1, never 0.** CIZ returns span gaps back to `DlyPrevDt` (the live `DlyRetDurFlg` values `D3`/`D4` prove it), so the next valid return already covers the missing day.
- **The anchor is the last row with a NON-NULL close**, not simply the last row. RESEARCH's snippet used a plain `.last()`; a PERMNO whose final row has no price would then anchor on a null and every adjusted value in its series would be NaN. The implementation filters first and joins the anchor back.
