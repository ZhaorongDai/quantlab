<objective>
Make the CRSP panel's identity choices explicit and reportable: which securities are in
it (the common-stock filter, D-06/D-17), which PERMNO owns a ticker on a contested day
(collisions, D-04), what happens where a ticker column changes company (PERMNO seams,
D-18), and the separate QQQ benchmark store (D-15) that is data only (D-16).

**Sequencing:** execute only after phase 03.9 is fully merged and plans 03.10-04, -05 and
-06 are merged. It extends `quantlab/dataset/crsp.py` from plan 05 and must keep
`tests/test_crsp_dataset.py` green (its scenarios are common stock, single PERMNO).

**Flagged interpretation of D-17 (reversible, config only):** D-17 states the predicate
`securitytype='EQTY' AND securitysubtype='COM'` AND states that it drops ADRs and units.
The live L11 rows show ADRs (`AD/EQTY/COM`) and units (`UG/EQTY/COM`) satisfy that
predicate, so the preset also requires `sharetype` in {NS, SB, CE} (every ShareType code
CRSP defines except AD and UG). That delivers every drop and every keep D-17 lists.
The filter report makes the effect visible, and a user who wants the literal two-column
predicate passes it as a dict.

Purpose: a user can trust that the equity panel holds what D-17 says, see exactly what was
removed and why, and never gets a fabricated return across two companies.

Output: `quantlab/dataset/crsp.py`, the new `CrspDatasetConfig` fields and classmethod,
`tests/test_crsp_identity.py`.
</objective>
