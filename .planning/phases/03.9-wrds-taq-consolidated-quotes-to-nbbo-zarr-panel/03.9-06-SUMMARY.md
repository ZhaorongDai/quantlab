# Phase 03.9 Plan 06: NBBO Dataset Integration Summary

NbboPanelDataset now takes session edges from the XNYS calendar (half days, DST, non-sessions refused, extended windows up to 04:00-20:00 ET) and builds its resampler from the config's filter knobs. It writes per-(session date, symbol) drop counts to a `<store>.nbbo_filter_stats.json` sidecar. Multi-day, multi-symbol conversion through `registry.convert` is resumable and gives the same store for `day` and `month` granularity.

## What was built

**Task 1: XNYS session bounds and filter-policy wiring (D-09, D-10, D-23, D-29)**
- The config setter constructs `XnysSessionCalendar(config.session_start, config.session_end)`. A window edge outside 04:00-20:00 ET is refused when the dataset is constructed.
- `_session_bounds` delegates to the calendar. The plan-01 localized-window body is deleted, so session edges are decided in one place only (no `ZoneInfo`/`replace_time_zone` in nbbo.py).
- `_resampler` is `NbboResampler(bar_interval, NbboFilterPolicy.from_config(config))`, and the window densifier calls `resample_with_stats`.
- The class docstring covers the XNYS edges, the D-29 half-day edge rule, window seeding, and the fact that an extended close lands on the next UTC day.

**Task 2: Sidecar, multi-day chunked conversion, encoding, rebuild (D-06, D-10, D-13, D-14, D-17, D-26)**
- `FILTER_STATS_SUFFIX = ".nbbo_filter_stats.json"`, the `filter_stats_path` property, and `last_filter_stats` (None until a window is resampled). The sidecar holds `config`, `by_session[date][symbol]` counts and `totals`, and is written with `write_json_atomically(indent=2, sort_keys=True)`. Windows the ledger skips leave it untouched.
- `_raw_axes_in_range` raises `ValueError` on an empty symbol list before any store is created.
- `_widen_fill_values` still returns `{}`; its docstring now says why NaN is the correct pre-listing value, counts included.
- The module docstring advises `granularity="day"` for sub-minute bars (a 1s S&P 500 day is about 11.7M bar-rows).
