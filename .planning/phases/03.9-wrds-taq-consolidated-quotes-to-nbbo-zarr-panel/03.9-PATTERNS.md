**`_fetch_page` contract** (alpaca.py:699-720). Returns `(frame, next_page_token)` projected to `RAW_COLUMNS`. **No aggregation or dedup, anywhere.** For WRDS, one page = one trading day's `complete_nbbo` table × one symbol batch. The token walks trading days, and `None` means done (RESEARCH Pattern 1). The server SQL is `COPY (SELECT … WHERE sym_root = ANY(...)) TO STDOUT`, with **no ORDER BY / GROUP BY / DISTINCT** (D-19). Add `wrds_row_ord` as the arrival ordinal within the page (`pl.int_range(pl.len())` over the frame in COPY order).

**Raw schema rules:** do not name a raw column `date` or `data_type`, because `_write_shard` overwrites and drops hive keys (base/acquisition.py:990-1000, 1104-1115). Rename TAQ `date` to `taq_date`. `time_m_nano` is typed-null (Int16) before 2018. `RAW_COLUMNS` is identical for every shard.

**Entitlement probe (D-21):** `has_schema_privilege('taqm_YYYY','USAGE')` per year before the first page. If a year is unentitled, raise a global error, not a per-symbol failure (see `_classify_error`, alpaca.py:688, for the classification hook).

### `quantlab/dataset/nbbo.py` (dataset + resampler)

**Analog A:** `quantlab/dataset/stock.py`

Hive schema (stock.py:40-51). The tick layout already exists, so reuse it unchanged:

DERIVED_HIVE_KEYS = ("month", "date", "data_type")

Override points (stock.py:501-551):
```python
def _raw_axes_in_range(self) -> tuple[list[str], pd.DatetimeIndex]:
    scan = self._scan_raw()
    symbols = sorted(str(s) for s in scan.select("symbol").unique().collect()["symbol"].to_list())
    timestamps = scan.select("timestamp").unique().collect()["timestamp"].to_list()
    return symbols, pd.DatetimeIndex(sorted(timestamps))

def _raw_data_to_xr_window(self, start_date, end_date, symbols=None) -> xr.Dataset:
    data = self._scan_raw(start_date, end_date)
    data = data.collect().to_pandas().set_index(["timestamp", "symbol"]).to_xarray()
    if symbols is not None:
        data = data.reindex(symbol=list(symbols))
    return data
```
The NBBO version must differ from this analog in four ways (RESEARCH Pattern 5):
- The timestamps must be **session-grid labels** (right-closed and labelled at bar end, D-22; XNYS via `exchange_calendars`, D-23), not observed record times.
- The window scan must go **by `date` hive key**, not a `timestamp` filter, so pre-open seed rows survive.
- The sort must be a stable sort on `(symbol, timestamp, wrds_row_ord)`. `_scan_raw` sorts only `["timestamp","symbol"]` and is not stable (stock.py:473).
- The `symbol` coordinate must be pinned to `str`. Raise on a window with zero symbols (empty-store todo).

Other overrides:
- Set `config_cls = NbboDatasetConfig` (pattern: base/data.py:1110-1111, `config_cls = DatasetConfig`).
- Override `_widen_fill_values()` to return `{}` (the base returns `{"anomaly_flag": False}`, base/data.py:869).
- Store counts (`n_updates`, ambiguous ties) as float64 (see `_pin_append_dtypes`, base/data.py:1084-1092).

**Analog B (the `_clean` override):** `quantlab/base/constituent.py:123-125`

Use RESEARCH Pattern 4 (filter with drop counts; stable total order; as-of snapshot; time-weighted spread and depth with zero duration on tied rows; within-day carry-forward only; NaN before the day's first valid NBBO; a NULL side becomes NaN, D-25). Keep carry-forward in the resampler and **never** in cleaning.py (cleaning.py:22-23 forbids filling), and state this in the docstring.

## Shared Patterns

### Credentials (every new module and the CLI)
**Source:** alpaca.py:30-31, :104-118, :528; registry `required_env` literals (:951-954).
Read credentials from env only in the transport `__init__`. Never put them on the config. Put them in `CREDENTIAL_ENV_VARS` so `_scrub` removes them from messages. `required_env` is restated as literals.

### Layer boundary
Acquisition never imports xarray or Zarr, and the Dataset never calls WRDS. `universe.py` and `sql_volume.py` import no acquisition module.

### Tick raw layout
Use `RAW_HIVE_KEYS["tick"] = ("data_type","date","symbol")` with `data_type="nbbo"`. The `date=` key is the ET session date (`SESSION_TIME_ZONE`), and timestamps are naive UTC `Datetime("ns")`. Never dedup tick rows.

### No config factories
Construct configs directly (user memory). The descriptor's `config_factory` is a classmethod on the provider (D-27).
