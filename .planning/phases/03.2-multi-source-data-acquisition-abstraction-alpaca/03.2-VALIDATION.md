## Sampling Rate

- **After every task commit:** Run `uv run pytest tests/test_<file>.py -x -q` for the file the task touched.
  **Plus, on every commit that touches `base/acquisition.py` or `acquisition/tiingo.py`:**
  `uv run pytest tests/test_tiingo_acquisition.py tests/test_tiingo_quota.py -q` (43 tests, seconds).
  D-02 requires no regression *at any commit*, not merely at phase end — this is the per-commit gate for the entire orchestration lift.
- **After every plan wave:** Run `uv run pytest -q`
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 30 seconds
