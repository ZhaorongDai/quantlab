**A. Resolve the free-tier SIP question (RESEARCH Assumption A7 / open question O-1).**
Alpaca's own documentation self-conflicts: three sources say the Basic tier reaches historical SIP
data older than 15 minutes, one says IEX is the only feed usable without a subscription. The
difference is material — if the second reading is right, free-tier quotes and trades are IEX-only,
roughly 2.5% of consolidated volume, and unusable for research. No amount of further reading settles
it. With credentials exported, run one request:

```
export APCA_API_KEY_ID=... APCA_API_SECRET_KEY=...
curl -s -o /dev/null -w '%{http_code}\n' \
  -H "APCA-API-KEY-ID: $APCA_API_KEY_ID" -H "APCA-API-SECRET-KEY: $APCA_API_SECRET_KEY" \
  'https://data.alpaca.markets/v2/stocks/trades?symbols=AAPL&start=2024-01-02T14:30:00Z&end=2024-01-02T14:31:00Z&feed=sip&limit=10'
```

`200` means the Basic tier reaches historical SIP and the free tier is sufficient for this phase.
`403` with a body about a subscription not permitting SIP means the IEX-only reading is correct.
Report which. Until then `feed` stays a `config.kwargs` parameter with no in-code default, which is
what D-12 requires either way.

**C. Probe the real symbol-per-request ceiling (RESEARCH Assumption A2).**
