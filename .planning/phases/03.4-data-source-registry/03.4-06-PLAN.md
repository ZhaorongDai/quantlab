<objective>
Reduce `ingest_alpaca.py` and `ingest_us_equity.py` to thin shells over the registry's programmatic
entry point, and give `ingest_us_equity.py --dry-run` a real coverage report on a machine with no
credentials.

Purpose: SC-6 says the in-repo ingest entry points must reach their source through the registry, so
the registry has a consumer in this repository and cannot rot into a side table for the console repo.
The subtle half is L-5: the constructor calls are the obvious vendor bindings, but the argparse
defaults that read vendor class constants are seven more per script, and a registry landing while
those remain would satisfy SC-6's letter with a vendor name still typed all over each file. The
other half is SC-3's visible consequence in this repository: `ingest_us_equity.py` currently skips
its own coverage report without a key, for a computation that is nothing but local file reads.

Output: two thin shells that name no vendor class, a credential-free dry run, and the D-15/SC-1/SC-6
locks.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → roster resolution → filesystem paths | `--symbols` and `--universe` become watermark and shard path segments |
| CLI arguments → storage root | `--data-dir` relocates every path the script writes |
| unconfigured machine → dry run | The dry run must answer with no credential present |
| shell process → vendor HTTP API | Credentials cross here, inside the vendor client only |
