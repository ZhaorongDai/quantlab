## Decisions Made

- **读者集合只信当场跑出来的命令。** 任务 1 先跑 `grep -rn "read_failure_manifest()" quantlab/`，输出逐字
  记录在本 SUMMARY，两个任务的 verify 各自重跑同一条命令并把文档断言在它之上。gap 2 的成因就是「继承」，
  再继承一次就是重造这个缺陷。
- **矛盾必须整句修。** 否定从句与两行后点名读者的从句一起替换；只改其中一句会留下同一个缺陷。
- **`example/pageledger.md` 纳入而非豁免。** 它承载的是同一句话的同一含义，改掉它才能让本计划的
  `<success_criteria>` 按原文为真，而不是围着一个明知被排除的文档做窄化。
- **`03.4-CONTEXT.md` D-18 / `03.4-REVIEW.md` / `03.4-VERIFICATION.md` 一律不改。** 它们是有日期的决策与
  发现记录；抹掉当时的认知就抹掉了决策为什么长成那样的理由。持久的更正写在 ROADMAP 与三份指南里。
- **`quantlab/acquisition/inspector.py` 源码里的同一说法不由本计划改。** 它归 plan 03.4-08 的任务 2，
  执行时确认该 docstring 已被更正（现文写着「the pre-write merge ... since 03.4-08 runs on every exit
  path of the resume loop, not only the cancel one -- also reads the manifest」），两个计划互不越界。
