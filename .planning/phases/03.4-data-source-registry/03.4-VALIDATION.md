## Sampling Rate

- **After every task commit:** the touched file's `uv run pytest tests/test_<file>.py -q`, **plus**
  the five suites that exercise `quantlab/base/acquisition.py` (which every progress / cancel /
  coverage change touches):
  `uv run pytest tests/test_tiingo_acquisition.py tests/test_alpaca_acquisition.py tests/test_acquisition_batching.py tests/test_tiingo_quota.py tests/test_page_ledger.py -q`
- **After every plan wave:** `uv run pytest -q` (~57 s)
- **Before `/gsd-verify-work`:** full suite green, **plus** a manual
  `uv run python ingest_us_equity.py --dry-run` with every credential unset, which must print a real
  coverage report instead of "skipped"
- **Max feedback latency:** 60 seconds
