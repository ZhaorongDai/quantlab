## Accomplishments

- **The tracer landed whole.** One path — registry → descriptor → vendor module → `Acquisition._run` → raw `.pqt` shard, with `ingest_tiingo.py` driving it — works and is asserted in a single end-to-end test rather than as five per-layer unit tests that could each pass while the seams between them did not meet.
- **Enumeration is complete from a cold import while `quantlab/acquisition/__init__.py` stays 0 bytes.** The vendor imports live at the bottom of `registry.py` in module-object form, which is what lets each descriptor be defined beside the class it describes and what keeps `import quantlab.acquisition.universe` from dragging a client into the process. Both halves are proved in credential-free subprocesses, because this pytest session has already imported both vendor modules and an in-process assertion would measure the session, not the import graph.
- **The credential contract is pinned in both directions for both vendors, with the real guards running.** The plan specified transport mocks; `mock_alpaca_client` replaces `_AlpacaMarketDataClient`, which *is* Alpaca's missing-credential guard, so a socket tripwire was used instead — strictly stronger, and it closes the "test double disables the control" threat (T-03.4-02-05) rather than walking into it.
- **A planted sentinel escapes nowhere.** `is_configured`, `credential_status`, `repr(descriptor)`, `repr(all())`, a real `AcquisitionResult` and every loguru record emitted during those calls were all checked. Types are asserted to be actual `bool`, because a non-empty credential string is itself truthy and would satisfy a truthiness assertion perfectly.
- **Four locks were mutation-verified**, not accepted on arrival (the 03.2 lesson in STATE.md): an unsorted `all()`, a list-backed `SOURCES` registered by `.append`, a value-returning `credential_status`, and a dropped vendor import each turn `tests/test_source_registry.py` red. The mutation run is what exposed that `test_enumeration_order` was vacuous as first written.

## Decisions Made

- **SC-1 means no vendor CLASS, not no vendor STRING.** `ingest_tiingo.py` keeps `DataSourceRegistry.get("tiingo")`: the script's whole identity is its vendor, and the stricter reading would require a `--source` flag, i.e. exactly the merged CLI D-15 forbids. Recorded inline at the `SOURCE` constant so the next reader does not "finish the job".
- **The D-04 test uses a socket tripwire, not the transport mocks the plan named.** See Deviation 3.
- **`AcquisitionResult` lives in `quantlab/base/acquisition.py`.** The base layer must not import the acquisition package; `registry.py` imports the type from `base`, so there is one definition and no cycle.
- **`download()`/`refresh()` keep `-> Self`.** The chaining idiom (`Dataset.from_raw_data().save()`) is repo-wide; `run()` reads `last_result` instead. `cancelled` is hard-wired `False` for now — plan 05 introduces the cancel token that can make it `True`, and the field says so in a comment rather than being omitted and retrofitted.
- **`coverage` on the result is computed by calling `coverage_report(requested)` after the manifest write.** That is a second sidecar traversal (~1.65 s on a 7.7k-symbol roster); accepted, because the alternative is a parallel counting path that could drift from `_partition_by_coverage`, which D-09 exists to prevent.

Flagged for plan 04, which introduces the credential-free inspector and may want a lighter path.
