### `quantlab/acquisition/registry.py` (registry, dispatch)

**Analog:** `quantlab/acquisition/universe.py:1249-1320`

**Class-level registration tuple + rationale-comment style** (`:1249-1274`) — copy the *shape*
and the *density of the `#:` rationale comment*, which is what makes this a registry and not a
list:

```python
    #: Both roster fetchers are deliberately ABSENT: they are full-exchange
    #: rosters with no membership-interval semantics and no coverage start,
    #: and D-02 locks `nasdaq_all` semantics exactly as they are. Adding
    #: either here would impose a boundary it must not have.
    MEMBERSHIP_FETCHERS: tuple[type[IndexMembershipFetcher], ...] = (
        SP500MembershipFetcher,
        Nasdaq100MembershipFetcher,
    )
```

`DataSourceRegistry.SOURCES` is the same ONE class-level tuple; per D-05 its elements are
`SourceDescriptor` **instances**, not classes. Keep it a `tuple` and REBIND it (`SOURCES += (d,)`)
— never `list.append` — because the `isolated_registry` fixture's `monkeypatch.setattr` isolation
depends on rebinding. Pin that invariant with a test (`registration_tuple_shape`).

**Consumption pattern to copy** (`universe.py:1300-1320`, `build()`): plain
`for cls in self.X_FETCHERS:` loops with the discriminator derived from a class/instance attribute
(`cls.CATEGORY` → `descriptor.vendor`). **Zero `if` branches on a vendor literal anywhere.**

```python
        frames = [
            roster_cls()
            .fetch()
            .with_columns(pl.lit(roster_cls.CATEGORY).alias("category"), ...)
            .select(self.CATALOG_COLUMNS)
            for roster_cls in self.ROSTER_FETCHERS
        ]
```

**Dataclass-config idiom for `SourceDescriptor` / `Capability`:** `quantlab/base/config.py:121-165`
(`AcquisitionConfig`, `to_dict() = asdict(self)`). Use `@dataclass(frozen=True)` for the descriptor
and capability (the config dataclasses are mutable because their setters mutate them; the descriptor
has no such lifecycle).

**Credential-name source of truth:** `quantlab/base/acquisition.py:393`
`CREDENTIAL_ENV_VARS: tuple[str, ...] = ()`, overridden at `tiingo.py:73` and `alpaca.py:520`.
Per RESEARCH's recommendation, RESTATE the names as literals on the descriptor and pin them with a
test — deriving `required_env=Cls.CREDENTIAL_ENV_VARS` makes D-04's demanded test a tautology.

**Vendor imports go at the BOTTOM of this file** (D-07 amendment), never in
`quantlab/acquisition/__init__.py`, which stays empty. Reason recorded in L-3: a non-empty
`__init__.py` runs vendor imports on every `import quantlab.acquisition.universe`, eroding the
volume guard's structural property while `tests/test_volume_guard.py` stays green.

**Do NOT use:** `quantlab/utils/module.py:get_cls_from_path` (the dotted-path idiom
`Acquisition.import_path`/`class_name` feeds). D-03 explicitly rejected it in favour of direct
class references. Note it here so planning does not drift back.

**The pattern to copy** (`pageledger.py:422-450`) — temp file in the SAME directory, `flush`,
`os.fsync`, `os.replace`, `unlink` on any `BaseException`:

```python
    def _flush(self) -> None:
        """Rewrite the sidecar ATOMICALLY.

        Written to a temp file in the SAME directory and then `os.replace`d, so
        a crash mid-write leaves either the previous valid ledger or the new
        one -- never a half-written file that cannot be parsed, which would
        make the next run unable to resume at all. Copied from
        `base/chunking.py:ChunkLedger._flush`, whose reasoning applies here
        unchanged.
        """
        directory = Path(self.path).parent
        directory.mkdir(parents=True, exist_ok=True)
        handle = tempfile.NamedTemporaryFile(
            "w",
            encoding="utf-8",
            dir=str(directory),
            prefix=Path(self.path).name + ".",
            suffix=".tmp",
            delete=False,
        )
        try:
            with handle:
                json.dump(self._payload, handle, indent=2)
                handle.flush()
                os.fsync(handle.fileno())
            os.replace(handle.name, self.path)
        except BaseException:
            Path(handle.name).unlink(missing_ok=True)
            raise
```

**Planner note (RESEARCH "Don't Hand-Roll"):** this would be the THIRD independent copy
(`ChunkLedger._flush` → `PageLedger._flush` → here). Extract ONE shared helper
(e.g. `quantlab/utils/atomic.py:write_json_atomically(path, payload, **json_kwargs)`) and have all
three call it; the `indent`/`sort_keys` difference between the two acquisition writers is a kwarg,
not a reason to fork. The docstring above is the rationale text to carry into the shared helper.

### `quantlab/base/coverage.py` — `CoverageLedger` (service, file-I/O) — THE D-09 EXTRACTION

**Analog:** `quantlab/base/acquisition.py` itself — this is a lift, not a rewrite. D-09 forbids a
second coverage predicate.

**Members to move** (all credential-free, all pure local file reads):
`_watermark_root` (`:147`, including the `/{data_type}` tick namespacing),
`_watermark_path` / `_read_sidecar` / `_read_watermark` / `_read_coverage` (`:168-234`),
`_legacy_policy` (`:1425`), `_coverage_status` / `_classify_coverage` / `_covers`
(`:1436/:1483/:1508`), and `_partition_by_coverage` (`:1519`).

**The single function that must not be duplicated** (`:1519-1552`):

```python
    def _partition_by_coverage(
        self, requested: list[str], from_watermark: bool
    ) -> tuple[list[str], dict[str, int]]:
        """Split `requested` into what still needs fetching, plus the counts
        the run reports. One pass, so each sidecar is read exactly once.
        """
        legacy_is_skipped = self._legacy_policy() == "warn"
        pending: list[str] = []
        counts = {"covered": 0, "widened": 0, "legacy": 0, "no_data": 0}

        for symbol in requested:
            coverage = self._read_coverage(symbol)
            status = self._classify_coverage(coverage, from_watermark)
            if coverage is not None and coverage["no_data"]:
                counts["no_data"] += 1
            if status == "covered":
                counts["covered"] += 1
                continue
            if status == "legacy":
                counts["legacy"] += 1
                if legacy_is_skipped:
                    continue
            elif status == "widened":
                counts["widened"] += 1
            pending.append(symbol)

        return pending, counts
```

**Extraction blocker to handle** (RESEARCH Pattern 6): `_data_type` (`:749`) is base-`None` but
`AlpacaAcquisition` overrides it as an **instance property** reading `_knob("data_type")` with no
default (`alpaca.py:557`). The ledger cannot construct an `Acquisition`, so `data_type` must be
passed IN to `CoverageLedger` (from `config.kwargs`) rather than read off a class.

`Acquisition` then **composes** the ledger and delegates; do not leave a parallel copy behind.
The D-09 test asserts both callers route through the *same function object*.

**Rejected alternative (do not drift to it):** `Acquisition.__new__(cls)` without `__init__`. It is
a legitimate *test* idiom (`tests/test_alpaca_acquisition.py:481`) but a half-constructed object in
production code.

**Analog A — the AST binding resolver**, `tests/test_volume_guard.py:717-745`. Copy this to prove

```python
def _resolved_imports(source_path, module_name: str) -> set[str]:
    """Every module `source_path` imports, as a fully qualified dotted name.

    Relative imports are resolved against `module_name`'s own package, which is
    the whole point: `from ..base.acquisition import X` and
    `from ..base import acquisition` name the same module as
    `import quantlab.base.acquisition` and must be seen as such. `from X import
    y` also contributes `X.y`, because `y` may itself be a submodule.
    """
    import ast

    package = module_name.rpartition(".")[0]
    tree = ast.parse(source_path.read_text(encoding="utf-8"))
    found: set[str] = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            found.update(alias.name for alias in node.names)
        elif isinstance(node, ast.ImportFrom):
            if node.level:
                base = package
                for _ in range(node.level - 1):
                    base = base.rpartition(".")[0]
            else:
                base = ""
            target = f"{base}.{node.module}" if base and node.module else (
                node.module or base
            )
            found.add(target)
            found.update(f"{target}.{alias.name}" for alias in node.names)
    return found
```
