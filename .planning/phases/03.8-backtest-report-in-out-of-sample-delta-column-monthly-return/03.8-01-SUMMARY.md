## Issues Encountered

- **`gsd check tdd-red-evidence` 的字段名是 camelCase**：`exitCode` / `targetTest` / `output`，用 snake_case 会被静默忽略并判成 `invalid_record`。另外它只解析 node `--test` 的 TAP，所以 pytest 的真实运行结果需要投影成 TAP（计数与失败测试名逐字抄自真实运行，未编造）。最终判定 `RED_EVIDENCE_OK`，target test 为 `test_the_reported_trade_counts_are_the_positions_view_not_exit_trades`（`assert 14 == 8`，exit 1）。
- **一次性测量脚本要显式加 `PYTHONPATH=.`**：`pythonpath = ["."]` 只对 pytest 生效，`uv run python /abs/path.py` 会把脚本自己的目录放进 `sys.path`，直接 `ModuleNotFoundError: No module named 'tests'`。脚本里也自己设了 `OMP_NUM_THREADS=1`，因为它会经过同时拉起 torch 与 xgboost 的模型代码，而 `tests/conftest.py` 的守卫对普通脚本不生效。
