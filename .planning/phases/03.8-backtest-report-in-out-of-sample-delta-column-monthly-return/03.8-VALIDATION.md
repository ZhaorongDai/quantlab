## The two failure modes that would otherwise pass silently

These drive the test *shapes* above. Coverage alone does not catch either.

1. **A delta column that silently drops a metric it should have differenced.**
   "Every delta cell is a number or a dash" passes when the predicate returns
   `None` for everything. The lock must be a **census**: assert the exact SET of
   row keys carrying a delta *and* the set that is dashed — both halves. A count
   assertion alone survives a predicate that differences the wrong four.
   *Mutation check:* `_delta` → `return None` unconditionally, and separately
   drop the `math.isfinite` check. Both must turn a test red; if the first does
   not, the test is vacuous.

2. **A heatmap whose month alignment is off by one.** Shape assertions (12
   columns, N rows, right non-null count) all survive the off-by-one. Feed ONE
   return in ONE month and assert the x label of the non-null cell (March 2024 →
   `'03'`). Then feed two returns in the same month of different years and assert
   both year rows.
   *Mutation check:* `period.month - 1` → `period.month` must turn that test red
   and ideally nothing else.

3. **(Item 3) A `positions` switch that did not actually switch.** Per-call
   `trades_type` is silently ignored, producing a byte-identical copy. Keep the
   `RotateOneOutEqualWeight` fixture (`tests/test_backtest_engine.py:676-708`) —
   on a fixture where every holding opens and closes once the two views coincide
   and the lock is vacuous. Assert against independently re-derived
   `pf.positions.records_readable` row counts, never the engine's own constant.
