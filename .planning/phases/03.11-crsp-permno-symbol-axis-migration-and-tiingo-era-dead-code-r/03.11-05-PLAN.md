<objective>
把成分股一侧的身份轴对齐到 PERMNO，并修掉「两边都对齐了、中间那层又强转回 str」这个第二层陷阱。

**为什么只改 `_build_intervals` 是不够的。** 前置调研只说了「两个面板轴不匹配 → `masking.py` 抛 ValueError
（好事）」。但本调研实跑发现：**即使 W3 把两边都对齐到 PERMNO，`UniverseMask` 仍然会挂**——
`masking.py:100-105` 的 `symbols` 属性把两侧都 `{str(symbol) for ...}`，`:190` 再拿这个字符串列表去
`.sel`，于是 `KeyError: "not all values found in index 'symbol'"`

`base/constituent.py:_densify`：`:198` 建列映射、`:266` 写值、`:269-270` 建 coord，三处各 `str()` 一次，
