## 三个复现（已在本机实跑确认，不要重新诊断）

```
{"intervals": [1,2,3]}                       -> AttributeError: 'list' object has no attribute 'get'
{"intervals": {"13407":[{"ticker":"FB"}]}}   -> KeyError: 'start'
[]                                            -> AttributeError: 'list' object has no attribute 'get'
```

三条走的是**两条不同的路**，这决定了守卫必须分两段：

| 输入 | `_intervals()` 这一步 | 逐个 PERMNO 的 `as_of` 这一步 |
|---|---|---|
| `{"intervals": [1,2,3]}` | 就在这里坏（payload 是 dict，intervals 不是） | 到不了 |
| `[]` | 就在这里坏（payload 不是 dict） | 到不了 |
| `{"intervals": {"13407":[{"ticker":"FB"}]}}` | **正常通过**，返回一个非空 dict | 在这里坏（span 缺 `start`） |

只加第一段守卫会让复现 2 继续崩。
