## data/ 在 worktree 下如何解析（operator P7，必须显式）

`.planning/config.json` 的 `use_worktrees: true`，而 `data/` 在 `.gitignore:169` 被 `data/*` 排除，
**所以 worktree 里根本没有 `data/` 目录**。已记录的事故形态是：计划里写死主仓库绝对路径 → 隔离执行读到主树
的旧 store → 报假绿。

本 plan 的解析规则，写死在测试与任务里，不留隐含：

```
QUANTLAB_DATA_ROOT = dirname( git rev-parse --path-format=absolute --git-common-dir )
```

`--git-common-dir` 在 worktree 里返回**主仓库**的 `.git`，在主树里返回自己的 `.git`，两种情况下父目录都是
主仓库根 `/Users/daizhaorong/projects/quantlab`。于是：**被测代码来自 worktree，被读写的数据来自主树**，
这正是想要的切分。`CrspStoreRebuilder` 拿到的是这个显式实参，没有任何 cwd 回退。
