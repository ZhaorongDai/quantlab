<objective>
把 `ticker` 从面板里彻底移出去、放进一个 as-of 可查的 sidecar，并在六个**人可见**的地方把它还原回来。

**为什么是 sidecar 而不是面板变量。** 一个 2-D `ticker(timestamp, symbol)` 字符串变量会撞三道既有守卫
（`backend.py:470-505` 与 `:984-1005` 都拒绝 symbol 维上非浮点且不在 `fill_values` 里的变量，`:1020-1044`
记录了字符串 dtype 的往返问题），而且 `crsp.py:1220-1229` 把每个数据变量都 `cast(pl.Float64)`。
一个 1-D `ticker(symbol)` coord 只能存「最后一个 ticker」，于是 FB→META 就丢了——PERMNO 13407 全程不变，
变的是它的 ticker。

**数据源已经存在。** `CrspSymbology.symbol_intervals()` 的输出契约逐字就是
`(permno, symbol, start_date, end_date)`，`permno` Int64、`symbol` String、两个日期 Date，按
`(permno, start_date)` 排序且已带缓存——**这正是 as-of 查询需要的区间表**，不要另起一套 ticker 历史读取。

Purpose: 让 PERMNO 轴对机器正确、对人仍然可读，而不用在面板里塞一个会把两家公司混起来的字符串列。
Output: `.crsp_tickers.json` 写侧 + `CrspTickerLookup` 读侧 + 六个展示点的还原。
</objective>
