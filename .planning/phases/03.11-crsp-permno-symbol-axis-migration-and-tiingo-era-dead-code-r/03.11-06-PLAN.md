<objective>
删掉 `quantlab/factor/universe_filter.py` 的条件 (a)——九条 ticker 正则及其开关与四个消费点，**只删 (a)**。

**为什么是删而不是关。** 九条正则全部要求字母（`^[A-Z]{4}[WRU]$`、`^Z[A-Z]ZZT$`、`-(?:WD|WI|CL)$` …），
对 `"10107"` 这样的 PERMNO 数字串一条都不匹配，于是 `is_common_ticker` 恒返回 True，整条过滤在 CRSP 面板上
**无声地变成 no-op**——它**看起来**在工作。把开关默认改成 False 留下的是一个仍会被 `to_dict()` 序列化、
仍在文档里描述、但实际什么都不做的旋钮。

**它的职责由谁承接。** CRSP 的 `security_filter`（`equity_common`，`crsp.py:202-224`）**更强**而不是等价：
CRSP 的类型词表里根本没有 warrant / right / preferred / test-code 的编码，所以九条正则里 7 类在 CRSP 不可能存在；
唯一真实的 "unit" 是 `sharetype=UG`，已被排除；而 CRSP 还额外排除了正则排不掉的 ADR（`AD`）、ETF/CEF、
未知类型行——**按日期**，并附一份审计报告。原正则的论证基础是对 Tiingo 14,481 个 `us_all` 代码的一次测量，
而且那份文档自己承认 2,310 个五字母命中里有 284 个没有旁证。

Purpose: 消灭一条会无声失效的过滤，同时拿到 D-05 点名要求显式记下的红利——`_mask_panel` 从此永不删列。
Output: 只剩阈值的 `UniverseFilteredFactor` + 一份写进 `example/universe.md` 的机制论证。
</objective>
