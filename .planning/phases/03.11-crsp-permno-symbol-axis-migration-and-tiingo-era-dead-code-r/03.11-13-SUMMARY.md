## Decisions Made

- **Widen the gate, do not refactor the import.** `quantlab/base/backtest.py:15`'s named vendor import is a real inconsistency with how `base/factor.py` solved the same problem, but the operator ruled (b): accept it, gate the file. Refactoring it would have been executing a rejected option.
- **Delete the field rather than restore a ticker.** The audit question is "was the drop correct". PERMNO (the key) plus `types` answers it. The status quo was the worst option because three test assertions had pinned the redundancy in place.
- **Replace every removed assertion, and add a key-set assertion.** Deleting the three lock assertions without replacement would have converted the gap from "guarded wrongly" into "unguarded". The two key-set assertions make the field's return a red rather than a silence.
- **Rewrite the hand-off comments instead of preserving them.** Both comments deferred a human-readable ticker to plan 09's sidecar. That hand-off was never picked up, and is the proximate cause of this gap; restating it would schedule the same failure again.
