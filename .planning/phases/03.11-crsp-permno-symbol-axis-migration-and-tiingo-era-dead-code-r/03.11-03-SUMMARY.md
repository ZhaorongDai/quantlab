## Decisions Made

1. **`_admitted_without_ticker` 用 `symbol_intervals().drop_nulls("symbol")`。** 这个字段问的是反事实问题——「ticker 轴会不会让这一行进来」——而 `label_rows` 自己正是 as-of join 到 `drop_nulls("symbol")` 上并丢掉贴不上的行。用**完整**区间表（含 null symbol）会一个都数不出来：never-ticker 的 PERMNO 是有区间的，只是区间上没有名字。实现逐步复制 `label_rows` 的两步（backward as-of join，再用 `end_date` 判定真的落在区间内），顺序一致。
2. **只数「一天都没被覆盖」的 PERMNO，不数部分覆盖。** 部分覆盖的证券在两种轴下都被准入了它有 ticker 的那一段；ticker 轴在中段丢掉的行是 `unlabelled` 计数，它随 plan 07 的符号学一起消失，不是这个字段的主题。
3. **warning 从 `_build_filter_report` 发出。** `_apply_security_filter` 的两个分支（有过滤器 / 无过滤器）都恰好到达这里一次；放在调用点必然写两遍。已在 docstring 里说明这个位置是刻意的。
4. **`test_crsp_identity.py` 的机器测试改写而不是删除。** 计划把这个文件的删除交给 plan 07，但本 plan 断开了它们测的机器。删掉会在 plan 07 之前留下一段保护真空，所以改写成同一批保护在 PERMNO 轴下的说法（尤其 T-03.10-16「两家证券永不合并」变成「两列，无需 universe，不拒绝转换」），保护转移而不是消失。
5. **`{zarr}.crsp_symbology_report.json` 断言为不存在。** 它的六个键全部是关于 ticker 轴的陈述，在 PERMNO 轴下结构性为空；一个只会说「什么都没发生」的 sidecar 读起来像「检查跑过了」的证据。这与 plan 10 的 must-have（最终重建后该文件不存在）一致。
6. **`_permno_breakdown` 的 `symbol` 字段现在复述 PERMNO，本 plan 不改。** 该字段的人类可读性由 plan 09 的 ticker sidecar 恢复；在此之前测试如实断言它等于 PERMNO，而不是假装它还是 ticker。
