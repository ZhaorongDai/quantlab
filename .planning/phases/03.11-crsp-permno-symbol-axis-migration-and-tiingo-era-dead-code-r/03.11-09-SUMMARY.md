# Phase 03.11 Plan 09: 把 ticker 移出面板、放进 as-of sidecar，并在人读的地方还原 Summary

**`{zarr}.crsp_tickers.json` 是一张 PERMNO -> ticker 的**区间表**（13407 在里面是 FB 与 META 两条，不是一个值），`CrspTickerLookup` 是它 stdlib-only 的 as-of 读侧，五个人可见点经一个注入的可调用打出名字——核心层因此一个厂商名都没多认识，而没有 sidecar 的面板输出一字未变。**

## Accomplishments

- **区间表，不是「每个 PERMNO 的最后一个 ticker」。** `_permno_breakdown` 用 `pl.col("symbol").last()` 聚合，照抄它就等于把 D-03 否决 1-D `ticker(symbol)` coord 的那个缺陷挪到外面一层：13407 的 2012 年会被归到 META 名下。sidecar 因此存 `{"13407": [{"ticker":"FB","start":"2012-05-18","end":"2022-06-08"}, {"ticker":"META", ...}]}`，两条断言逐字钉住这个边界。唯一与 `_permno_breakdown` 保持一致的是 JSON key 用 `str(permno)`。
- **一个类，两种失败纪律，而且这是设计不是疏漏。** `as_of` 是严格的单值提问，缺文件抛带 `CrspTickerLookup:` 前缀 / 路径 `!r` / 补救动作的 `FileNotFoundError`，损坏抛带 `type(exc).__name__` 的 `ValueError`；`label` 是展示层的批量入口，**永不抛**——缺文件、损坏、未知 PERMNO 一律回落成数字。理由写进了模块 docstring：让一次回测因为一份审计文件缺失而中断，等于让可读性层比它注释的东西更脆。
- **「非 CRSP 面板一字未变」不是靠分支维持的。** 判据是**盘上有没有那个 sidecar**，不是面板属于哪个厂商：Tiingo / Alpaca 的库旁边没有那个文件，`label()` 于是原样回落。三个文件里各有一条 control-arm 断言（强平记录 `symbol == axis_symbol`、`browse_zarr` 的 PERMNO 文案**不得**出现在 ticker 轴的拒绝里、`missing_labels` 在没有 lookup 时就是数字），所以「回落坏掉了」和「还原根本没做」都会被抓到。
- **核心层没有多认识任何厂商。** `quantlab/base/model.py` 里 `CrspTickerLookup` 出现 **0 次**：回测器是这条链上唯一知道价格库在哪的层，它把 `label` 作为一个 `(symbols, day) -> list[str]` 的可调用装到模型上（`_align_and_predict`），模型只会调用它。纯净性 gate 的禁词表只有四个子串（其中 `StockDataset` 正是 `CrspStockDataset` 的子串），但遵守的是那条规则的**意思**而不是它的字面。
- **A1 实测升级为 VERIFIED。** `grep -c symbol quantlab/utils/backtest_report.py` 结果是 **2**，两处分别是 `:346` 的局部变量 `marker_symbol` 与 `:360` 的 `marker={"symbol": marker_symbol, ...}`——plotly 的三角形状，不打任何标的名。`report.html` 确认无需还原，该文件在整个 diff 里零改动。
- **新 sidecar 与重建清单同一次提交。** 写侧有 store-exists 守卫，意味着重建**永远**不会覆盖 `.crsp_tickers.json`；不把它加进 `CRSP_SIDECAR_SUFFIXES`，一次缩小了 roster 的重建就会留下一份用旧 roster 的名字给新 store 署名的文件（T-03.11-32 的同一个形状）。
