### 1.2 Schema：**不要**照抄 `_permno_breakdown`

`crsp.py:1095-1126` 的 `_permno_breakdown` 用 `pl.col("symbol").last()` 只保留**最后一个 ticker**

### 1.3 读侧：`CrspTickerLookup` —— 照抄 `CrspReference.manifest` 的惰性缓存形状

**Analog（`quantlab/dataset/crsp_reference.py:310-326`，逐字）：**

```python
        """`manifest.json` as a dict.

        Raises the same shaped `FileNotFoundError` as `table()`: a reference
        directory with tables and no manifest has no recorded vintage, and a
        panel built against an unknown vintage cannot be checked for the
        anchor drift D-08 warns about.
        """
        if self._manifest is None:
            path = self.reference_dir / MANIFEST_NAME
            if not path.exists():
                raise FileNotFoundError(
                    f"{type(self).__name__}: no {MANIFEST_NAME} under "
                    f"{str(self.reference_dir)!r}; the reference tier records "
                    f"its CRSP vintage there. Re-run the reference pull."
                )
            self._manifest = json.loads(path.read_text(encoding="utf-8"))
        return self._manifest
```

要照抄的四点：**(1)** `None` 哨兵字段 + 惰性读，与 `CrspSymbology._intervals`
（`crsp_symbology.py:167`，`symbol_intervals` 的 `if self._intervals is not None: return self._intervals`）
同一惯例；**(2)** 缺文件抛 `FileNotFoundError`，消息带 `{type(self).__name__}:` 前缀、带路径 `!r`、
**并给出补救动作**；**(3)** `json.loads(path.read_text(encoding="utf-8"))` —— 全仓 sidecar 读法统一是这一行
（`crsp.py:1295`、`backtest.py:571`/`:952`、`model.py:369` 同形）；**(4)** 派生值走 `@property`
（对照 `product_end` 把 manifest 字段解析成 `date`）。

**损坏文件的错误形状**照抄 `crsp.py:1293-1303` 的 `except (OSError, ValueError) as exc:` 分支
（带 `type(exc).__name__`、说明这个 sidecar 记录了什么、给出「删 store 与 `.crsp_*.json` 重建」的出路）。

**类的放置：** operator 的 standing preference 是「新组件必须 class-based/layered，不要平铺脚本」，
且 `dataset/` 下已有 `crsp_reference.py` / `crsp_symbology.py` / `crsp_membership.py` 三个
**单一职责的 CRSP 辅助模块**并排存在 —— 新文件 `quantlab/dataset/crsp_tickers.py` 与它们同层同形。
`CrspSymbology` 的 `__init__(self, security_info, overrides=None)` 是「吃一个已读好的数据对象」，
而 `CrspReference.__init__` 是「吃一个路径，自己惰性读」——**`CrspTickerLookup` 跟 `CrspReference` 走**
（`__init__(sidecar_path)`），因为它的消费者是展示层，拿不到 polars frame。

### 2.2 `quantlab/dataset/masking.py` — 去掉 `symbols` 的 `str()` 强转

**同一个类里紧邻的正确写法（`:93-98` 逐字）：**

```python
    @property
    def timestamps(self) -> pd.DatetimeIndex:
        """The overlapping timestamp axis: a plain inner join, sorted."""
        market = pd.DatetimeIndex(self.market["timestamp"].values)
        membership = pd.DatetimeIndex(self.membership["timestamp"].values)
        return market.intersection(membership).sort_values()
```

**要改的那个（`:100-105` 逐字）：**

```python
    @property
    def symbols(self) -> list[str]:
        """The intersected symbol axis, sorted."""
        market = {str(symbol) for symbol in self.market["symbol"].values}
        membership = {str(symbol) for symbol in self.membership["symbol"].values}
        return sorted(market & membership)
```

→ **改成 `timestamps` 的形状**：`pd.Index(...).intersection(...).sort_values()`，
dtype 由数据自己决定，返回类型标注从 `list[str]` 改为与轴一致。
同一文件的 `in_window_members:122-127` 与 `missing_members:130-134` 也各有一处 `str(symbol)`，
**三处必须一起改**，否则 `missing_members` 的集合差会在 str 与 int 之间恒为全集
（Pitfall 2 的 "missing_count 突然变成全体" 就是这个）。

**但 `report()` 的 `missing_symbols` 是 D-03 点名的 6 个展示点之一**（`:134-163`，docstring 逐字
「The list is never truncated and never sampled -- a truncated list is worse than none」）——
这里要经 `CrspTickerLookup.label()` 还原 ticker，**且不能因此破坏「永不截断」这条既有承诺**。

### 4.2 Chokepoint #2 — `tests/conftest.py:1460-1560` 的 symbol 坐标编码模型

**要加第三个 arm 的四件套（逐字）：**

```python
SYMBOL_COORD_ENCODINGS = ("fixed_width", "variable_length")        # :1460

def symbol_coord(symbols: Sequence[str], encoding: str) -> np.ndarray:   # :1463
    if encoding == "fixed_width":
        return np.asarray(list(symbols))
    if encoding == "variable_length":
        return np.array(list(symbols), dtype=object)
    raise ValueError(
        f"unknown symbol coordinate encoding {encoding!r}; "
        f"accepted values are {SYMBOL_COORD_ENCODINGS[0]!r} and "
        f"{SYMBOL_COORD_ENCODINGS[1]!r}"                            # ⚠ 硬编码 [0]/[1]，加 arm 时会说谎
    )

def stored_symbol_dtype(path: str):                                 # :1507
    return zarr.open_group(path, mode="r")["symbol"].dtype

def stored_symbol_encoding(path: str) -> str:                       # :1517
    dtype = stored_symbol_dtype(path)
    if dtype == np.dtypes.StringDType():
        return "variable_length"
    if getattr(dtype, "kind", None) == "U":
        return "fixed_width"
    raise AssertionError(...)
```

**四条必须照做的约定（都写在 analog 自己的 docstring 里）：**

1. **按 dtype KIND 分类，永不按宽度字面量** —— `stored_symbol_encoding` docstring 逐字：
   「By dtype KIND … never by a width literal」。int64 arm 相应地按 `kind == "i"` 判定，**不要** pin `int64` 字面量。
2. **`stored_symbol_dtype` 读 zarr 原始 dtype，不读 `xr.open_zarr` 的解码值** —— docstring 逐字说明
   「the DECODED value is what hid the defect」。int64 arm 同样要走 `zarr.open_group`。
3. **`symbol_coord` 的每个 arm 都要有「为什么是这个拼写」的实测注释** —— `:1468-1487` 的映射表是范例。
   int64 arm 建议 `np.asarray(list(symbols), dtype=np.int64)`，并注明它在 zarr 上落成什么。
4. **`:1490-1495` 的错误消息用 `SYMBOL_COORD_ENCODINGS[0]!r}` / `[1]!r}` 硬编码两项** ——
   加第三个 arm 时**这段消息必须同改**（改成遍历元组），否则它会漏报第三个合法值。
   这是 RESEARCH Pitfall 6 之外的**第二处**元组耦合点。

**连带 6 个消费者**（RESEARCH §R2-E 已列全，含前置调研漏掉的 `tests/test_nbbo_dataset.py:476,:501`），
