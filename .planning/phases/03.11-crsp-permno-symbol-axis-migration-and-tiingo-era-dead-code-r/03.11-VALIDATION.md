## Sampling Rate

- **After every task commit:** Run the plan task's own `<automated>` command（多为 < 60 s）
- **After every plan wave:** `uv run pytest -q --ignore=tests/test_factor_hierarchy.py -p no:cacheprovider`
- **Before `/gsd-verify-work`:** 全套必须绿，且相对 03.10 基线（1694 collected）零新增失败
- **Max feedback latency:** 110 秒（全套实测 102 s）

  `QUANTLAB_DATA_ROOT="$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")"` 前缀运行，
  它把 worktree 里的**代码**与主仓库里的 **data/** 显式接起来（operator P7 的假绿事故形态）
