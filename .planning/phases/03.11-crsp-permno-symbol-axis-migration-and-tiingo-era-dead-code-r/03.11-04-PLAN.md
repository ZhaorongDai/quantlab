<objective>
修掉 int64 轴在**模型对齐**与**稠密化 / chunked append** 两条链路上的硬破坏点。

这两条链路的共同形态是：把一个已经对齐好的轴**强转回字符串**，然后拿字符串去 `.sel` / 求集合差。
在 ticker 轴上它是无害的恒等变换，在 PERMNO 轴上它要么抛一个误导的 `KeyError`，要么让「加了哪些标的」
变成「全体」。RESEARCH §R2-B 已实跑复现前者
（`membership check at model.py:1201-1203 passes: True` → 最后一行 `KeyError: "not all values found in
index 'symbol'"`），后者由本 plan 在 `base/data.py:800` 补上——它不在前置调研的清单里。

Purpose: 让 DATA-03 的「上层不改」主张在换轴后仍然成立——真正要改的是轴管道，不是因子/模型/回测的业务逻辑。
Output: 三端同步的 checkpoint 符号契约、不再强转的已存轴读取、三处统一的数值序。
</objective>
