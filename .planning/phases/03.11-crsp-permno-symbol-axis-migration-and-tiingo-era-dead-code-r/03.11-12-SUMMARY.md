# Phase 03.11 Plan 12: The Corrupt Half of `label()`'s Never-Raises Contract Summary

**`CrspTickerLookup` now degrades to PERMNO digits for a sidecar that parses but is shaped wrong — not just a missing one — with a two-stage guard in `label()`, shaped `ValueError` refusals in `as_of()`, and a model-layer regression proving `predict_panel`'s happy path survives it without touching `model.py`.**

## Accomplishments

- **The half of the contract that was fiction is now true.** `label()` claimed to never raise when the sidecar is "missing or corrupt". Missing was real; corrupt was not. `as_of()` indexed `span["start"]`/`["end"]`/`["ticker"]` unguarded, `intervals` itself might not be a dict, and `label()`'s single `try` wrapped only the intervals read. All three reproduced payloads now fall back to the digits.
- **The guard is in two places, because damage arrives by two routes.** `{"intervals": [1,2,3]}` and `[]` break while the table is being read; `{"intervals": {"13407":[{"ticker":"FB"}]}}` reads a perfectly good non-empty table and only breaks inside the per-PERMNO `as_of`. A guard on the first alone leaves the third crashing — which is exactly what shipped. Both halves are documented in a table in the test module so neither is deleted later as redundant.
- **The worst call site is pinned at the model layer, not just in unit tests.** `quantlab/base/model.py`'s `_spell` in `predict_panel`'s `extra` branch is a bare call on the happy path: a panel carrying untrained symbols is merely dropped with a `logger.warning` and the prediction completes. A half-written audit file — whose only job is putting letters in a log line — used to turn that successful `predict_panel` into a `KeyError`. `test_a_corrupt_ticker_sidecar_leaves_the_warning_working` holds that line, and `model.py` has zero logic change.
- **`as_of()` stays strict, and its refusal became readable.** Structural damage raises a `ValueError` naming the class, the path, what is wrong and the rebuild — the same four-part shape the `payload` property already used — instead of a bare `AttributeError: 'list' object has no attribute 'get'`.

## Decisions Made

- **`as_of()` raises rather than returning `None` on structural damage.** The strict entry point asks one question about one security on one day; answering "no name that day" when the truth is "I cannot read this file" hands the caller a plausible-looking wrong answer.
- **The guard sits in the lookup, not at the six display call sites.** Wrapping each caller in its own `try` is the same guard written six times, with six chances to miss the seventh.
- **An absent `intervals` key is not damage.** Only a key present with the wrong type is a refusal.
- **`except Exception` is refused.** The exception tuple is spelled out (`FileNotFoundError`, `ValueError`, `KeyError`, `AttributeError`, `TypeError`), the last three as backstops, so a real bug in this module still reaches the caller.
- **`03.11-09-SUMMARY.md` stays as written.** It records what was believed then; editing it would erase the evidence that the claim was once false.
