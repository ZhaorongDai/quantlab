**GAP-D-01 (locked by the user this round, at the same authority as 03-CONTEXT.md's D-numbers, and superseding D-02's formula):**

The US-equity `amount` proxy becomes typical-price dollar volume: `amount = volume * (high + low + close) / 3`.

The user chose this over an OHLC4 average and over dropping vwap-derived features for US equities. Rationale: `vwap` then equals the typical price `(H+L+C)/3`, genuinely distinct from `close`, so the VWAP block regains information content without inventing a data source. Tiingo's EOD endpoint supplies no native dollar-volume column (confirmed: `date/open/high/low/close/volume` plus `adj*` variants plus `divCash/splitFactor`), so a real vendor column is not an option today — which is exactly why the existing double guard (`"amount" in data_columns and "amount" not in data.data_vars`) must be preserved verbatim: it keeps the door open for a future source that does supply one.

Everything else about D-02 stands: the synthesis stays a single central assignment in `StockDataset._to_kunquant()`, after the `adj*` rename so the inputs are the ADJUSTED series, never duplicated per factor class.
</locked_decision>
