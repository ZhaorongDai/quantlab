## Task 2（缩减版）：真实数据门写入 + 合成回归

### 写入的用例

`tests/test_crsp_rebuild_measurements.py::test_the_real_store_reproduces_its_adjusted_columns(rebuilt)`，+149 行，逐条对齐 plan 的 `<behavior>` / `<action>`：

- **挂既有 module-scoped `rebuilt` fixture**，签名就是 `(rebuilt)`；文件里 `CrspStoreRebuilder(` 仍然只有 fixture 里那一处
- **I-5**：四个不变量直接从 `measurement.metrics` 取（`adj_close_le_zero == 0`、`close_eq_zero == 0`、
  `adj_close_nan == structural_gaps`、`adj_volume_nan == structural_gaps`），**不重新打开面板算一遍** ——
  `_measure()` 是权威口径
- **I-1**：`xr.open_zarr(measurement.store_path)` + `try/finally` + `close()`，对每个 symbol 用
  `np.isfinite(close) & (close > 0.0) & np.isfinite(cumfacshr)` 求**同一个索引**上的第一个可用行
  （三条同行谓词 = CR-02 的形状，D-05；`close > 0.0` 是 CR-01 的哨兵排除），断言该行
  `adjClose == pytest.approx(close, rel=1e-12)` 且 `adjVolume == pytest.approx(volume, rel=1e-12)`
- **覆盖率断言**：`checked == metrics["symbol_count"]`；任何一行都不满足的标的被收进 `anchorless` 并**具名报出**，不静默少查
- **`print(...)` 证据**：`store_path`、`dims`、`metrics`（七个键）、`I-1 checked PERMNOs`、
  `I-1 exact == PERMNOs`（预期 < checked，正是不能用 `==` 的现场证据）、`I-1 anchorless PERMNOs`
- **docstring 写明为什么是 `rtol` 不是 `==`**：`close_A * G_A / G_A` 在 IEEE-754 下不保证逐位等于 `close_A`，
  真实 store 上精确相等只有 514/520；把 6 个末位差当失败会诱导放宽到 `approx()` 默认的 `rel=1e-6`，
  从而同时盖掉一个真实的 5e-06 级偏移
- **没有**引入任何条件跳过 marker，**没有**改 `_data_root()` / `_fresh_backup_dir()` / `rebuilt` / `EXPECTED_WRITTEN_SIDECARS`
- 模块级新增 `import numpy as np` / `import xarray as xr`（本文件的既定 import 风格，不套用
  `tests/test_crsp_dataset.py` 的函数体内约定）
