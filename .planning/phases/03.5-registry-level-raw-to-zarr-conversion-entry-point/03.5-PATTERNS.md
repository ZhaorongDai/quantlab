**Body pattern — construct from the descriptor, delegate, return the outcome** (`registry.py:359-363`):

→ `convert()`'s equivalent: look up the `Capability` for `(config.market, config.frequency,
data_type)`, read `capability.dataset_cls`, refuse on `None` (SC-7), construct
`dataset_cls(dataset_config)`, call `from_raw_data_chunked(...)`, build and return `ConversionResult`.

**Placement constraint** — the vendor imports MUST stay last (`registry.py:366-396` banner,
imports at `:395-396`):

Insert `convert()` above this banner.

**Docstring convention:** `run()`'s docstring is the house style — bolded claim headers
(`**ACQUISITION-ONLY, and that is D-14's amendment stated as code.**`), decision IDs inline, and
an explicit statement of what the function does NOT do. `convert()`'s docstring must carry the
D-11 admission verbatim in spirit: *it does not run the guard; the caller does.*

**Note — `run()`'s docstring is now partly stale.** `registry.py:328-331` still says "The three
ingest entry points convert in three genuinely different modes -- unconditional whole-window,
per-frequency, and opt-in chunked -- each with a differently-sized RAM guard". D-06 kills that

## Shared Patterns

### Estimate/assert split
**Source:** `quantlab/acquisition/universe.py:1667` + `:1785`
**Apply to:** `estimate_chunked_panel` / `assert_chunked_panel_fits`
The estimator returns a dict and NEVER raises; the asserting sibling calls it, returns on fit, and
raises a message carrying the full arithmetic plus a concrete remedy. One copy of the arithmetic.

### Result types live in `quantlab/base/`
**Source:** `quantlab/base/acquisition.py:113-118`
**Apply to:** `ConversionResult`
The base layer must not import the acquisition package; `registry.py` imports the result type from
`base/` (`registry.py:47` is the existing instance of this import direction).

### Keyword-only `reporter` / `cancel` with `None` defaults
**Source:** `quantlab/acquisition/registry.py:305-308`; `quantlab/base/progress.py:111` `ProgressReporter`, `:228` `CancelToken`
**Apply to:** `convert()`
Call ARGUMENTS, never assigned onto a config — `to_dict()` is `asdict(self)` and lands on disk,
where a `threading.Event` cannot be serialised (`run()` docstring `registry.py:344-349`).

### Every print lives in `quantlab/utils/cli.py`
**Source:** `quantlab/utils/cli.py:736` `print_volume_estimate`
**Apply to:** `print_chunk_report`, and to `convert()`/`estimate_chunked_panel` by exclusion —
`quantlab/acquisition/` and `quantlab/base/` produce report objects only (D-13, SC-4).
Renderers take `print_fn=print` and RETURN their input so they compose around the guard call.

### Descriptor fields are `#:`-commented and optional-with-default
**Source:** `quantlab/acquisition/registry.py:78-85`, `:112-131`
**Apply to:** `Capability.dataset_cls`
Frozen dataclass, extended by adding OPTIONAL fields only; never a dict.

### Empty `__init__.py`, full dotted imports, no re-exports
**Source:** `quantlab/acquisition/registry.py:366-394` (the banner explains why
`quantlab/acquisition/__init__.py` stays 0 bytes)
**Apply to:** every new import this phase. `quantlab/config/__init__.py` is the one pre-existing
exception.

### Docstring voice
**Source:** `run()` (`registry.py:302`), `from_raw_data_chunked()` (`base/data.py:520`),
`assert_chunked_panel_fits()` (`universe.py:1844`)
**Apply to:** every new function. Bolded claim headers, decision IDs (`D-06`, `T-13w-03`) inline,
an explicit statement of what the function does NOT do, and named test references where a claim is
pinned. Stale docstrings are AMENDED in the same edit that falsifies them — `registry.py:328-331`
and `base/data.py:439-445` are two that D-06/D-08 falsify.
