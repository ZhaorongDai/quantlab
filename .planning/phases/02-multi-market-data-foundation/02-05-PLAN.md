Retrofit `SpotKlineDataset`/`spot_kline_config()` onto the new `market`/`frequency` config schema landed in Wave 2 (CONTEXT.md D-04) and insert the shared `dedup_raw_frame()` call before `SpotKlineDataset._raw_data_to_xr()`'s final `.to_xarray()` conversion (D-05, matching the same pattern the Tiingo/StockDataset slice applies). This keeps the fix config-driven and consistent with the existing factory-function pattern, with zero new filesystem mutation.

plan -- `DatasetConfig` (`base/config.py`) is a plain (non-frozen) `@dataclass`, so

change to support the override.
