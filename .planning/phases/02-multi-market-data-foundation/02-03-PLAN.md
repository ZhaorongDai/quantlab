<objective>
Build the shared, reusable raw-market-data cleaning module (CONTEXT.md D-05..D-08) that both the Tiingo and Binance vertical slices (Waves 3-4) plug into, and wire its post-conversion half centrally into `base/data.py:Dataset.from_raw_data()` so every current AND future `Dataset` subclass gets dedup-adjacent NaN-gap preservation, anomaly-flagging, and schema validation "for free" — directly satisfying ROADMAP Success Criterion 4 (a new market/frequency needs only a subclass + config, never a change to this shared hook).

This module is split into two entry points per 02-RESEARCH.md Pattern 2/3: `dedup_raw_frame()` operates on the pre-`to_xarray()` tabular (polars) data and MUST be called by each subclass's `_raw_data_to_xr()` directly (Waves 3-4's job, not this plan's — a non-unique `(timestamp, symbol)` index crashes `to_xarray()` before the base-class hook ever runs). `clean_market_data()` operates on the already-converted `xr.Dataset` and is wired centrally, once, here.

Purpose: Today `my_ops/preprocess.py` only has factor-normalization ops — there is no raw-market-data cleaning logic anywhere. This is genuinely new code, not a refactor, and is the single "waist" both data sources pass through (ROADMAP Success Criterion 3).
Output: `dataset/cleaning.py` (new), `base/data.py:Dataset.from_raw_data()` modified to call it, full unit test coverage for all four cleaning rules.
