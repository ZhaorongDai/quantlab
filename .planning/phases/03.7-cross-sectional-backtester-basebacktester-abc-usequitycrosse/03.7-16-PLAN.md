<objective>
Close UAT gap G-03.7-8. DL `predict_panel` mislabels symbol coordinates whenever the recorded training symbol
list is not sorted.

Purpose: two causes act together (AND-gate, `.planning/debug/dl-predict-panel-symbol-coord-misalignment.md`).
(1) `DLModel._align_prediction_symbols` returns the panel in record order, and `predict_panel` reads output
coords from that panel, while `to_array` re-sorts the symbol axis before building the array. Values follow
sorted order and coords follow record order. (2) `_save_model` records `self.symbols` in raw backend order,
which is unsorted whenever train()/train_cv() run on a backend filled without collect(). A hand-edited record
triggers the same state. The fault is latent today because collect() sorts, and every existing test uses sorted
SYMBOLS and a position-invariant head.

Per user decision, symbol-sorted order is the contract. to_array's sort and DL training stay unchanged.
Diagnosis evidence P4 shows that preserving record order end-to-end corrupts the values of existing
position-sensitive checkpoints. Re-sorting after membership alignment fixes existing and new checkpoints alike.

Output: model-layer fix, position-sensitive regression tests, and dated doc corrections.
</objective>

<flagged_assumptions>
- **Belt-and-braces re-sort in `BaseModel.predict_panel`.** The gap lists it as optional. It is included
  because it makes the coord/value agreement a property of the one shared pipeline rather than of each hook. The
  cost is one extra `sortby` on the feature panel per prediction.
- **The "position-sensitive head" is `MLPRegressor`.** Its module flattens `[T, S*F]`. The RNN heads are also
  position-sensitive by construction, but they need no separate lock: the fix sits in the shared
  `predict_panel` / `_align_prediction_symbols` path they all go through.
- **The single-symbol boundary passes on arrival.** A one-element record is always sorted. It is kept as a
  boundary lock (a real run of the drop-extras path on a 1-symbol network), not claimed as red evidence.
- **03.7-REVIEW-FIX.md is a dated record.** Its WR-02 line gets an inline dated correction and the original
  wording stays, the same discipline example/*.md follows.
