## Sampling Rate

- **After every task commit:** run the quick command for the test files that task touches.
- **After every plan wave:** run the full suite command and compare with the baseline. The passed count must rise by exactly the new tests, with no new failures.
- **Before `/gsd-verify-work`:** the full suite shows no failures beyond the baseline set.
- **Max feedback latency:** 60 seconds.
