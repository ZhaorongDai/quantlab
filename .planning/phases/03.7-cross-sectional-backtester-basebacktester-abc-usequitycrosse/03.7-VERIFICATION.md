# Phase 03.7: Cross-sectional backtester Verification Report

**Phase goal:** Users can turn a trained return model into a reproducible cross-sectional US-equity backtest:
- `run()` runs a model backtest.

- The engine is vectorbt, with t+1 open fills and long-only/long-short TopN target weights.
- Every run reports in-sample and out-of-sample results, persists its artifacts and data fingerprints, and can be rebuilt from its own config.
