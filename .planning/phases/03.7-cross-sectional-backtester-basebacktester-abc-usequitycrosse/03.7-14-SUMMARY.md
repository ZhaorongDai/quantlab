## Decisions Made
- **Public-surface lock:** functions, classmethods, staticmethods, properties, `cached_property` and `partialmethod` count as methods. Plain class attributes (`config_cls = CrossSectionBacktestConfig`, `MARKET`, `STATS_METRICS`) are configuration and stay allowed. `config_cls` is a class and therefore callable, so a plain "no public callable" rule would wrongly fail it.
- **D-04 lock:** only function bodies are scanned, not class bodies, because D-04 explicitly allows column names as class attributes on the backtester.
- **Resolver:** `_resolved_imports` keeps `__init__` as the last module component, so the single "strip `level` components" rule is correct for both plain modules and package `__init__` files.
