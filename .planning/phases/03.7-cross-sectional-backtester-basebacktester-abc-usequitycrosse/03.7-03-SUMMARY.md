## Issues Encountered
- `select` aligns `scores` and `next_fill_price` by dimension name (`transpose`) and by shape, not by coordinate labels. Two panels with the same shape but a different symbol order would be combined position by position. No test here exposes this, because the backtester's single call site builds both panels from one axis. Plan 03.7-06 owns the reindex of predictions onto the price axes (D-06, RESEARCH Pitfall 14). Nothing was changed here. If a caller outside `run()` ever feeds `select`, a coordinate-equality guard belongs in `select`.
- zsh `pipestatus` is 1-indexed, so the first run echoed the exit code via a fallback. The pytest summary lines were used as the evidence. No code impact.
