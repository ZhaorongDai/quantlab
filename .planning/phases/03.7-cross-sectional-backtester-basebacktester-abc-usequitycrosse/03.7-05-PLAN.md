<objective>
Make `BaseModel.predict_panel` (D-29) correct for every shipped head. Lock its contract (label order, coords, all-NaN masking, error cases), and add the head adapters its generic path cannot serve:
- RNNRegressor and RNNClassifier return tuples from forward (D-33).
- MLPRegressor's inference contract is a flat `[T, S*F]` matrix.

Delete the stale `RNNClassifier._vecbt` hook and its lock (D-37).

Purpose: the backtester reads predictions only through predict_panel, so any head it cannot serve is a head that cannot be backtested.

Discovery recorded for the user: D-33 lists MLP among the generic heads that "keep the plain [T,S,L] path". The code says otherwise. `MLPRegressor._init_model` builds `nn.Linear(num_symbols * num_features, ...)`, and `tests/test_dl_models.py::test_mlp_regressor_trains_two_epochs_and_predicts` documents that its `predict()` takes the flattened matrix. The plain path would raise a shape error inside the first Linear layer. This plan therefore adds an MLP adapter to satisfy D-29 ("must handle DLModel tensor output"), without changing MLP's public `predict()` or module.

Output: head adapters, contract tests, `_vecbt` removal.
</objective>
