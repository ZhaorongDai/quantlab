<objective>
Persist the cross-validation fold geometry. `train_cv` writes a versioned `cv_folds.json` into its project directory (D-30, D-36), which `run_cv` (plan 03.7-10) will read to backtest every fold's out-of-sample segment. In the same model-layer pass, delete the stale in-model backtest hooks (D-37): backtesting now lives only in `quantlab/backtest/`.

Purpose: `run_cv` can only replay the folds a training run actually used if the geometry is on disk, versioned, and equal to what training returned.

Discovery recorded for the user: `tests/test_model_cv.py` asserts the exact contents of the CV project directory in two places (`_assert_golden_fold_dirs` and the skipped-fold test near line 431). Writing `cv_folds.json` there, as D-30 requires, would turn those goldens red without any fold geometry changing. This plan filters exactly `cv_folds.json` out of those two listings and asserts that the file exists. Every golden value is kept, and the change is annotated in the module docstring.

Output: manifest writing in `train_cv`, a new manifest test file, the golden listing accommodation, and the D-37 deletions with locks.
</objective>
