# Phase 03.7 Plan 15: G-03.7-7 run_cv spurious checkpoint date warning Summary

**run_cv now checks each fold checkpoint only against cv_folds.json. Every train-date check compares the bars each date pair selects on the price calendar (pandas slice_indexer, shared with `_training_window`), so a normal 8-fold run_cv logs 0 date warnings instead of 8.**
