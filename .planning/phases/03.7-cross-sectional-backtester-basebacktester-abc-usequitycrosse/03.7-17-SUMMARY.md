# Phase 03.7 Plan 17: G-03.7-9 model-level checkpoint variable check Summary

**`BaseModel.load()` now checks `trained_on.factor_names` / `label_names` (names and order) before building the model, with a legacy fallback and deduplicated warnings. XGBoost and DL heads alike refuse reordered or different variables with a named ValueError. The backtester delegates to this single check and has no comparison of its own.**

## Accomplishments

- `BaseModel._read_checkpoint_sidecar` is now the only parser for the `config.json` beside a checkpoint. A missing file returns None. A file that is not a JSON object raises ValueError naming the file. `_read_trained_symbols` reads through it.
- `BaseModel._assert_trained_variables(p)` handles each kind (factor, then label) from its best record. A `trained_on` list gets a strict check. Failing that, the legacy flattened `factors[]`/`labels[]` `factor_names` is compared, and a mismatch still raises. With neither, the kind has no record. All comparisons run before any warning:
  - At most one legacy warning (naming the kinds and the recorded names).
  - At most one no-record warning (naming the path). Its wording avoids "has no config.json".
- `load()` calls the check after the suffix check and before `_read_trained_symbols` / `_read_checkpoint`. A DL checkpoint with a different factor count now gets the named ValueError instead of torch's `size mismatch`.
- Warning dedup: `__init__` creates a per-instance `_emitted_load_warnings` set, and `_warn_load_record_once` skips exact duplicates only.
- `BaseBacktester`: `_saved_variable_names` and `_assert_checkpoint_variables` are deleted. `_load_model_checkpoint` now runs: existence check, `_read_checkpoint_config`, `model._assert_trained_variables(path)`, DL-only feature collection, `model.load(path)`. The no-sidecar warning now covers only training dates, and still contains "has no config.json" and the path.
- New test module `tests/test_model_load_variables.py` (13 ids) and two new backtester tests in `tests/test_backtest_dates.py`.
- Dated G-03.7-9 paragraphs in `example/model.md` and `example/backtest.md`.
