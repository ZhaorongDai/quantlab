# Phase 03.7 Plan 01: Backtester Tracer Summary

**`run()` loads a checkpoint, re-dates the factors, predicts a panel through `BaseModel.predict_panel`, builds TopN target weights, fills them in vectorbt at the next bar's adjusted open, and writes a run directory. One end-to-end synthetic test proves the whole path.**

## Accomplishments
- `quantlab/base/backtest.py` holds the `BaseBacktester` ABC and its D-02 `run()` template. The config setter validates in order: type first, then model_mode, checkpoint, rebalance_periods, fees, slippage, init_cash, date order, and finally D-08 rejects any benchmark. The base class also provides the warm-up counted in bars on the price calendar, cache-proof re-dating, the D-03 weights contract assertion, and a run directory that is never overwritten and gets atomic JSON writes.
- `BaseModel.predict_panel` puts all the xarray-to-array-to-predict-to-xarray plumbing in the model layer. Rows where every feature is NaN are masked to NaN. The `_predict_panel_array` hook is a plain method, so the `__abstractmethods__` sets stay unchanged.
- The engine, selector and market are split per D-01: `VectorBtBacktester` is the engine layer, `CrossSectionTopNSelector` and `rebalance_mask` handle selection, and `US_EQUITY_MARKET` is a `MarketSpec`. The two adjusted column literals appear only in that spec.
- `to_jsonable` converts NaN, inf, Timestamp, Timedelta, numpy scalars, Path and Enum into strict JSON values.
- `tests/backtest_fixtures.py` provides the synthetic fixtures every later 03.7 plan shares: a price store with delist/list hooks, the Polars `PastReturnFactor` and `ForwardReturnLabel`, a deterministic `FirstFeatureHead`, and the model builders.

## Decisions Made
- `run()` normalizes the window dates to ISO once, using `pd.Timestamp(str(x))`. Every date written into a dataset or factor config is then a plain ISO string. The dataset setter's normalization only runs when a whole config is assigned.
- In the fixture, the raw price group is the adjusted group x1.7 and `adjOpen` is noise around the previous `adjClose`. A raw-vs-adjusted mix-up or an open-vs-close mix-up therefore produces a different fill price. Mutation M3 confirmed this.
- The tracer test's docstring now says what the test does NOT lock, with the plan that owns each gap (see Mutation verification).
