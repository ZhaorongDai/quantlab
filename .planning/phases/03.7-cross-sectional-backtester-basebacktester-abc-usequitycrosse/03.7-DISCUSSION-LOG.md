## 选股与权重构造

**多空时权重怎么分配？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 多空各 50%，组内等权 | 毛敞口 100%、净敞口 0，符合项目「净/毛敞口 ≤100%」的决定 | ✓ |
| 多空比例可配置 | 例如 70/30，校验毛敞口 ≤100% | |
| 按预测值大小加权 | 组内按预测值或排名分配权重 | |

**每期选多少只怎么定？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 固定只数 top_n | 每期选预测最高的 n 只（多空时另选最低的 n 只做空） | ✓ |
| 按分位数 | 每期选前 x% | |
| 两种都支持 | 配置里二选一 | |

**模型有多个标签时，用哪个预测值来排序选股？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 配置指定标签名，默认第 0 个 | 标签名不存在时报错 | ✓ |
| 所有标签预测取平均 | 不同期限的收益尺度不同 | |

**调仓日怎样的股票不能选？可选的不足 n 只时怎么办？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 剔除无预测/无价格，不足就少选 | 权重在入选股票间均分，并打 warning | ✓ |
| 剔除同上，不足 n 只就整期空仓 | 更保守 | |

## 模型准备与日期对齐

**配置成「重新训练」时，模型的训练/测试区间从哪里来？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 用模型自己 config 的日期 | 回测器不修改模型 config；回测区间只用于预测和判断样本内外 | ✓ |
| 回测配置里写训练区间，覆盖模型 config | 同一个模型会有两处可以改日期 | |

**计算因子时起始日往前推多少（预热）？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 按因子 window 自动推算 | 取最大 window，按交易日历换算成日期 | ✓ |
| 配置里显式写 warmup_periods | 由用户指定预热 bar 数 | |
| 自动推算，配置可覆盖 | 两者结合 | |

**run_cv 从哪里拿每折的日期和模型文件？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 读项目目录下的 cv_folds.json | 由 train_cv 写出；训练和回测可以分开跑 | ✓ |
| 文件路径和 train_cv 返回值都支持 | 两种输入方式都接受 | |

**判断样本内时，训练区间怎么算？**

| 选项 | 说明 | 选中 |
|------|------|------|
| 训练末尾延长标签前视期数 | 有效训练区间为 [train_start, train_end + 标签期数] | ✓ |
| 只按 train_start ~ train_end | 会把紧跟训练段的几期误判为样本外 | |

**用户的选择（自由填写）：** 回测要输出 config。以后直接加载这份 config，就能加载所需的数据和类，重新跑同一个回测；所有参数必须一致，确保可复现。请查一下现在的模型类能不能直接从 config 构建。回测器也要能从回测器的 config 直接构建出所有需要的东西。

**跟进核查结果：**
- 已实测：Alpha101Stock + Return 标签 + XGBoostRegressor 的 config 往返重建后完全一致。
